KIEN NATURE PORTFOLIO
=====================

HOW TO OPEN
1. Extract the ZIP file completely.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Do NOT move the project folders out of the portfolio folder. The project links use relative paths.

FILES
- index.html      Main portfolio
- style.css       Olive green / white nature-themed design
- script.js       Navigation, reveal animation, botanical motion
- projects/activity-1/   DOM event activity
- projects/activity-2/   Promise dashboard activity
- projects/activity-3/   jQuery student/table activity

PROJECT LINKS
The three "Open activity" links point to local HTML files inside the projects folder.
Activity 3 includes a local jQuery copy, so it does not need an internet connection.

EDITING CONTACT INFO
Search index.html for "your@email.com" and replace it with the correct email.
